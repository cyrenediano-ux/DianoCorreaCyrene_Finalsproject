SIRAM CAFE WEBSITE SOURCE

Files:
- index.html: page structure/content
- style.css: visual design and responsive styling
- script.js: navigation, cart/order demo, edit mode and localStorage behavior
- assets/: extracted image files used by the page

To preview: keep this folder structure intact and open index.html in a modern browser. Google Fonts are loaded from fonts.googleapis.com, so an internet connection is needed for the selected fonts; the page otherwise uses fallback fonts.

The order feature is a front-end demonstration only. It does not send orders to a server or process payments.
